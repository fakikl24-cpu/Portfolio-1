Will it Web-Scrape?

After trying to scrape mulitple websites in Portfolio 3, I’ve decided to make a shiny app showing which websites can be scrapped and which cannot, as well as with reasons I found in my research. It was a frustrating process but I’m hoping that making a resource for others will bring some joy out of the pain. I’ve included proof of my tries underneath the shiny app. This will hopefully serve as a resource for others and for myself.

ui <- fluidPage(
  theme = bslib::bs_theme(bootswatch = "spacelab"),
  titlePanel("Will it Web-Scrape?"),
  
  sidebarLayout(
    sidebarPanel(
      selectInput("website", "Which website do you want to scrape?", 
                  choices = c("Youtube Playlists", "Nyx Cosmetics", "Elf Cosmetics", "Yelp", "Wikipedia"))
    ),
    
    mainPanel(
      h3("Results"),
      uiOutput("results")
    )
  )
)
